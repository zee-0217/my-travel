# 예산 입력·검색 장소 추가·관광지 사진

## 예산

총예산과 숙박 예산 상한은 `1,200,000`처럼 천 단위 쉼표로 입력합니다. 숫자 키패드, 붙여넣기, 입력 중 커서 위치를 지원하며 서버에는 정수로 전달합니다. 저장된 일정 열기, 기본값 초기화, 사진 지역 조건 적용에도 같은 형식을 사용합니다.

## 검색한 장소를 일정에 추가

- 검색 카드에서 추가할 날짜·방문 시각·종료 시각을 고르고 **일정에 추가**를 누릅니다. 시간순으로 배치하고 기존 일정 화면·지도·검증을 갱신합니다. 동일 날짜의 같은 장소는 중복 추가하지 않습니다.
- 미리보기에서도 추가할 수 있습니다. 이후 AI 계획을 생성하면 미리 선택한 장소를 생성된 일정에 반영합니다. 반영 실패 항목은 경고에 표시합니다. 미리보기 단계의 다른 장소와 금액은 샘플입니다.
- 새로 추가해 바뀐 자동차 구간은 기존 경로로 대체하지 않습니다. 비용 합계도 다시 확인할 때까지 미확인입니다. 장소 수·시간 중복·확인된 운영시간 등 기존 검증을 적용하며, 채팅으로 AI에게 동선을 다시 정리하도록 요청할 수 있습니다.
- **직전 수정 되돌리기**로 추가 전 상태를 복원할 수 있습니다. **변경사항 저장**으로 현재 일정을 보관하세요.
- 살아 있는 AI 수정 세션에는 `/api/plan/places`가 서버에 보관된 NAVER 실제 검색 결과 참조만 사용합니다. 검색 결과는 최대 200건·30분간 메모리에 보관하며, 브라우저에서 위조한 장소명·좌표를 서버 검증 근거로 사용하지 않습니다. 이후 Agent 수정에서도 추가 장소의 실제 검색 근거를 재사용합니다.
- 새로고침 뒤 불러온 저장 일정은 브라우저에서 직접 추가하고 다시 검증합니다. 서버 수정 세션 만료 시에도 직접 추가를 지원합니다. 새로운 API 조회나 예약은 자동 수행하지 않습니다.

## 사진 롤링과 조건 선택

제주·부산·경주·강릉·서울·전주·여수·순천·속초의 사진 9종을 제공합니다. 6.5초마다 다음 사진으로 바뀌며 이전·다음·일시정지 버튼으로 제어합니다. 마우스를 사진 위에 올리거나 사진 내부에 키보드 초점이 있으면 자동 넘김을 잠시 멈춥니다. 브라우저의 동작 줄이기 설정에서는 자동 재생을 시작하지 않습니다.

**다음 목적지, 기분 좋은 하루**는 클릭 시 현재 보이는 사진의 지역으로 여행 조건을 채웁니다. 기간·인원 등은 추천값으로 채우며 AI 생성은 생성 버튼으로 시작합니다. 사진이 넘어가더라도 입력해 둔 여행 조건을 자동으로 바꾸지 않습니다. 사진 출처와 이용 조건은 각 사진 아래 및 `public/images/destinations/CREDITS.md`에 있습니다.

검증: `npm.cmd test`, `npm.cmd run audit:interactions`, `npm.cmd run audit:sky`.
