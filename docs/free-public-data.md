# 무료 운영정보·날씨 연동

## 날씨

`get_weather`는 기상청을 먼저 조회하고 실패하거나 날짜 예보가 없으면 키 없는 Open-Meteo Forecast API를 사용합니다. `WEATHER_FREE_FALLBACK=false`로 대체 기능을 끌 수 있습니다. 기존 기상청 키는 유지됩니다. 날짜별 최대 16일 범위에서 실제 반환된 시간대만 사용하며, 범위 밖은 미확인입니다. 10분 캐시를 사용합니다.

- 공식 문서: https://open-meteo.com/en/docs
- 무료 API는 비상업용이며 호출 한도가 있습니다. 상업 서비스로 전환할 때 무료 사용 조건을 재검토하세요: https://open-meteo.com/en/terms
- 화면과 Agent Trace에 실제 제공자를 표시합니다. Open-Meteo 자료는 CC BY 4.0이며 기상청 자료로 표시하지 않습니다.
- 2026-11-24 현재 설정된 기상청 API 허브 키로 실제 조회 시 HTTP 403이 반환됐습니다. API 허브의 단기예보 활용 권한·키 상태를 확인할 수 있지만, 대체 예보는 별도로 사용할 수 있습니다.

## 영업시간·숙박 공개정보

무료 한국관광공사 국문 관광정보 서비스: https://www.data.go.kr/data/15101578/openapi.do

1. 공공데이터포털에서 위 서비스의 활용 신청을 합니다.
2. 발급된 서비스키를 로컬 `.env`의 `TOUR_API_KEY`에 입력하고 저장합니다. 기상청 API 허브 키와 별개입니다. 인코딩·디코딩 키를 모두 처리합니다.
3. 서버를 재시작한 뒤 장소나 숙소의 **공식 공개정보 확인 요청**을 누르고 채팅 요청을 보냅니다. 또는 채팅에 영업시간·숙소 공개 요금표 확인을 요청합니다.

Agent가 필요할 때 `get_place_details`를 선택하며, 서버는 실제 NAVER 검색 결과의 장소 참조와 여행 날짜를 확인합니다. TourAPI `KorService2`의 `searchKeyword2`, `detailIntro2`, 숙소의 `detailInfo2`를 조회합니다. 이름과 좌표/주소로 장소가 유일하게 연결되는 경우에만 적용합니다. 다른 지점으로 추측 연결하지 않습니다.

정규 영업시간과 휴무 규칙이 단순하고 명확할 때만 일정 검증에 반영합니다. 계절별 시간, 공휴일 예외, 야간 영업 등 해석이 불명확한 정보는 원문과 출처·조회시각을 표시하고 확인 필요로 남깁니다. 공공 등록 운영정보도 임시 휴무·변동은 별도 확인해야 합니다.

숙소의 체크인·체크아웃과 공개 계절별 객실 참고 요금을 표시합니다. 공개 참고 요금은 선택 날짜·인원·객실의 실제 견적이 아니므로 여행 예산 합계에 포함하지 않습니다. 시설 전체 객실 수는 남은 객실 수로 표시하지 않습니다.

## 실요금·객실 재고의 한계

현재 연결한 무료 공공 API는 날짜별 실제 판매 요금과 예약 가능한 객실 재고를 제공하지 않습니다. 요금은 `unknown`, 객실 가능 여부는 `unknown`으로 유지하며 가능한 객실이 없다고 단정하지 않습니다. 웹 검색의 가격 문구로 이를 대체하지 않습니다. 실시간 공급사 계약·인증이 없는 상태에서 유료 API를 자동 호출하지 않습니다. 예약 기능은 구현하지 않으며 공식 예약 링크는 기존 서버 검증 근거가 있을 때만 표시합니다.
